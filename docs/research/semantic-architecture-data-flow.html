Airflow + dbt + Iceberg + Trino + AtScale/Cube 資料流程

一份 Git semantic contract，產生兩個可替換 runtime：AtScale 面向企業 Universal Semantic Layer；Cube 面向自管與 embedded analytics。

資料平面控制與契約語意 runtime消費端
核心原則：Git semantic contract 只有一份；AtScale SML 與 Cube YAML 是 runtime binding。OpenMetadata 管治理與發現，不負責產生查詢。

資料流：Parquet → S3-compatible storage → Iceberg → Trino → dbt marts。發布流：Airflow → CI/review → AtScale/Cube → BI/Python/AI。
